# Beginner's guide

`MicroSegWorkbench_Beginners_Guide.pdf` (to read or print) and `.pptx` (to present): 30 slides, one step per slide,
with numbered markers on screenshots of the real application and ATTENTION boxes where beginners usually go wrong.
Screenshots use synthetic micrographs and a simulated network drive. Use it next to the in-app Help page and
[ROLLOUT](../ROLLOUT.md). Rebuild after UI changes with the scripts in `tools/guide/`.
